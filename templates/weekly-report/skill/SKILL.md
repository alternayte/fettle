# Weekly report

## Steps

1. Read the notes of the week in shared/notes/.
2. Use search_history to find the work that finished this week.
3. Group the items by project.
4. For each project, write: done, next, risks. At most three lines each.
5. Save the report as shared/reports/<year>-W<week>.md and attach it to the chat.

## Rules

- One page at most.
- Name people only when the notes name them.
