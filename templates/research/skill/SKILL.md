# Source summary

## Steps

1. Split the question into parts that you can look up.
2. For each part, open at least one primary source and read it.
3. Write one point per fact. Put the link after the fact: [source](URL).
4. End with open questions, if any.

## Rules

- No fact without a source.
- Quote numbers exactly as the source gives them.
