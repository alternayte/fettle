# Inbox triage

## Steps

1. List the new mail since the last triage.
2. Put each mail in one group: answer today, answer this week, read later, no action.
3. For each mail in "answer today", write a draft reply of at most 5 sentences.
4. Report a table with sender, subject, group and "draft" or "no draft".

## Rules

- Never send or delete mail. The user sends drafts.
- A mail that asks for money, passwords or account changes goes to "answer today" with the note "check this sender".
