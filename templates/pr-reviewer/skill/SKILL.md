# Pull request review

## Steps

1. Read the description and the diff.
2. Run the tests in the computer when the repository has them.
3. List bugs with file, line and fix.
4. List missing tests.
5. List clarity points, at most five.
6. End with a one-line summary: ready, ready after fixes, or not ready.

## Rules

- Never approve, merge or post. The user posts the comments.
