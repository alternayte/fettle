# Trademarks

"Fettle" and the Fettle logo identify the software of the Fettle project at <https://github.com/alternayte/fettle>.
The licences of the code do not give rights to the name or the logo.
This page tells you how you can use them.

## Forks

The licences let you fork the code.
You can distribute a fork, or run it as a service for other people.
Then the fork must use a different name and a different logo.

- Do not use "Fettle" in the name of the fork.
- Do not use a name that is similar to "Fettle" and can cause confusion.
- Remove the Fettle logo and the app icons from the fork.
- Change the product name in the UI, the desktop app, the installers, the images and the package names.
- Do not publish the images of the fork under `ghcr.io/alternayte` or with a name that starts with `fettle`.

You can say that the fork is "based on Fettle" in its description, if the statement is true.

## Uses that need no permission

- Use the name "Fettle" to refer to the project, for example in an article or a talk.
- Say that your product works with Fettle, if the statement is true.
- Run Fettle without changes under its own name, for yourself or for your organization.
- Distribute the official release files without changes.

## Uses that need permission

- Use the name or the logo in the name of a product, a service, a company or a domain.
- Use the name or the logo in a way that suggests that the Fettle project supports or makes your product.
- Change the logo.

Ask for permission in an issue on the repository.
