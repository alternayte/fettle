Connect Chrome to Fettle

  1. Install the Fettle extension in Chrome.
  2. Keep this page open. Click the Fettle icon in the Chrome toolbar.
  3. In the extension, click Connect.

If this browser is not Chrome, open the extension in Chrome and type the server and the code.
